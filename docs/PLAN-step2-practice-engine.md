# Step 2 Plan: Practice engine

Scope: drill rounds, spaced repetition for words and missed questions, progress tracking, and the daily "Today" session. It runs on the 161 seed questions plus the 1,000-word deck. Question volume comes in step 3, so Levels 2–4 will have almost nothing to practice yet. That is expected.

Done when: you can press "Start today's session" and finish a ~20 min session; Practice works per lesson; wrong answers come back via SRS; Progress shows accuracy by topic; all tests pass; works on the phone.

## Engine (pure, unit-tested)
- `engine/dates.js`: local-day helpers (`localDay`, `addDays`, `dayDiff`).
- `engine/srs.js`: Leitner boxes (1, 3, 7, 16, 35 days). Right = up one box, wrong = back to box 1, due tomorrow.
- `engine/mastery.js`: topic and section accuracy with recent answers counting more (half-life 14 days); weakest-topic picker.
- `engine/picker.js`: choose N questions (unseen first, then last-wrong, then least recent), shuffle options.
- `engine/wordq.js`: turn a word card into a 4-option question (Italian→English or English→Italian) with same-category distractors.
- `engine/session.js`: build the daily session: reviews due, 10 new words, drill on the last-read lesson, weak-spot drill, exam set (when exam-section questions exist). Short mode = reviews + weak spot.

## App
- `app/bank.js`: loads all question files listed in `content/questions/index.json` (generated by `tools/build-index.js`).
- `app/quiz.js`: the one-question-at-a-time runner: progress bar, feedback, explanation, Report button, results screen. Records answers, updates SRS and streak.
- Screens: Practice (topics, rounds of 10), Session (Today flow), Progress (accuracy by topic, 14-day activity, weak list). Lesson page gets a "Practice this lesson" button.
- Service worker precaches every question file named in the index.

## Rules
- Words always enter SRS on first answer. Questions enter SRS only when answered wrong.
- A wrong answer is asked again once at the end of the same round.
- Exam sections serve only `verified: true` questions.
